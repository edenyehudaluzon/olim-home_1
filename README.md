# 🏠 Olim Home

פלטפורמה לחיבור בין עולים חדשים לבעלי דירות בישראל.

---

## איך להריץ את הפרויקט

```bash
git clone https://github.com/edenyehudaluzon/olim-home_1.git
cd olim-home_1
npm install
npm start
```

פתח בדפדפן: [http://localhost:3000](http://localhost:3000)

---

## מה יש באפליקציה

- **עמוד נחיתה** עם מונה חוזים חי, ביקורות, ובחירת שפה לפני הרשמה
- **הרשמה** — דייר או בעל דירה (שם, טלפון, אימייל, ארץ, שפות, אישור קליטה)
- **חיפוש דירות** — פילטור לפי עיר, מחיר, חדרים, שפת בעל הדירה, זמינות
- **דף נכס** — גלריית תמונות, צ'אט עם בעל הדירה, סגירת חוזה, שמירה למועדפים
- **הוספת נכס** — לבעלי דירה, כולל תמונה, מסמך טאבו, סטטוס זמינות
- **פרופיל** — עריכת פרטים אישיים + רשימת דירות שמורות (❤️ דירות שאהבתי)
- **סטטוס התקדמות לחוזה** — עקוב אחר כל שלב: פנייה ראשונית → ביקור בנכס → משא ומתן → חוזה נחתם
- **התראות** — toast אוטומטי כשדירה שמורה חוזרת לזמינות
- **שתי שפות** — אנגלית (ברירת מחדל) ועברית, כולל כיוון RTL/LTR ותרגום ערים ושפות
